# Bug checks — 2026-09-14

## Results

- T1000 dual.4 and T114 dual.3: full builds passed. Each build validated UF2 block structure, target partition, vector table, Nordic DFU ZIP metadata/CRC, and identical application payloads in ZIP and UF2.
- Both boards: actual Cortex-M4-compiled transport helpers executed in Unicorn with mocked USB/BLE. Malformed frames, queue handling, disconnect behavior, fairness and priority passed.
- Both boards: four package rejection tests passed, including malformed headers, wrong target addresses, duplicate addresses, truncation and invalid vectors (multiple subcases).
- T1000: all three motion presets, sleep/refresh boundaries, no-fix backoff, sensor fault, manual override, timestamp rollover, unknown identity, each initialization-write failure, invalid acceleration data and 10,000 deterministic state transitions passed in ARM emulation.
- T1000 software I2C backend: stuck clock, stuck data and no-ACK scenarios returned failure within the mocked operation budget.
- Configurator: 127 tests passed, including mixed capability gating, JSON roundtrip, write verification failures and batch workflows.

## Bugs fixed

- T1000 thermistor conversion could access past either end of the calibration table and divide by zero on invalid readings. Boundaries are clamped and invalid readings are omitted from temperature telemetry.
- T1000 periodic coordinate-copy timing now uses unsigned elapsed time across millis rollover.
- GPS parser state is cleared on wake and timestamp progress is required for fresh-coordinate handling; a cached fix cannot keep a failed acquisition alive indefinitely.

## Scope

T114 remains dual.3 with no motion feature. T1000 is dual.4 experimental. Tests emulate compiled helper logic with mocked peripherals, not complete virtual radios. RF, real USB/BLE scheduling, accelerometer electrical behavior and battery life are untested on this candidate. Existing user-reported dual.2 hardware successes do not validate these new features.

## Reproduce

Install requirements-dev.txt and run python build.py. Run python tests/run_transport.py and python tests/test_package.py. Configurator tests: python -m unittest discover -q in its source directory with the packaged runtime dependencies available.
