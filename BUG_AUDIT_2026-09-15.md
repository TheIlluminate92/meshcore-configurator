# V4 and shared configurator audit — 2026-09-15

Development version: 0.7.5-dev, branch everyday-radio. Stable releases remain
separate. This audit uses synthetic data, mock radio operations, real localhost
TCP sockets and the packaged Windows app; it does not claim physical radio tests.

## Fixed

- Replaced recursive TCP parsing with bounded iterative parsing and ordered frame
  dispatch. A complete 350-contact response is accepted, including randomized
  fragmentation; a 5,000-frame flood closes rather than exhausting recursion.
- Wait for socket close, cancel and await background tasks, clear stale data,
  and reject sends on closed connections. Repeated disconnect is safe.
- Wi-Fi setup checks radio identity again during read-back, rejects malformed
  status types and empty user-info addresses, and checks pending profile edits
  before opening setup.
- Retained paired tuning writes, boot-compatible value limits, and verification
  of both changed and preserved tuning fields.

## Validation

137 unittest cases pass, including the existing profile, batch, history,
permissions, recovery, updater and display tests. New network coverage uses
real local sockets plus deterministic malformed/fragmented/coalesced streams.
The final windowed EXE passed `--smoke-test`: successful startup, 31 settings
and an opened history store.

Firmware-side tests and build records live in the private companion firmware
repository. They cover both V4 variants plus T1000/T114 shared command guards,
with board-specific version IDs and validated output packages.

## Remaining limits

No phone pairing, Wi-Fi association, RF range, power draw or live radio writes
were performed during this pass. Wi-Fi uses trusted-LAN Companion TCP without
application authentication/encryption. Only one active configuration writer is
supported across the shared USB/BLE/Wi-Fi Companion session state.

Passwords are write-only; their acknowledgement is not a claim that association
succeeded. Reread the radio after setup to check its IP address. USB/BLE is
required to change Wi-Fi settings so the transport survives network restart.
